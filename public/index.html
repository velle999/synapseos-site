A Linux desktop with an AI that runs on your own computer.

SynapseOS is a free operating system built on Arch Linux. It has its own desktop and apps, and a language model that runs locally, so you can ask for things in plain English without an account, an API key, or anything leaving your computer.

Download 1.0.1 Installation guide

Free and open source · 64-bit PCs · 4.6 GiB · rolling release

What it’s like to use

Ask the shell in plain English

The shell, synsh, works like any other until you type something that isn’t a command. Then it asks the model running on your machine what you meant and shows you the command it came up with. Nothing runs until you press Enter. 

syn find the big files in Downloads
  → du -ah ~/Downloads | sort -rh | head -20
  Enter to run · Esc to edit it first

  • An assistant that does things

    vibe is a chat window and a terminal command. It opens folders, apps and settings panels, changes settings, reads and edits files, and runs commands, and it asks before it changes anything. It speaks, takes dictation and answers to its name. It uses the local model, or Claude or OpenAI if you give it a key.

  • Private from the start

    The model sits on your disk and runs through llama.cpp. There’s no SynapseOS account or server, and nothing reports back. The installer suggests Mistral 7B Instruct (about 4.1 GB), and you can say no. Once it’s installed, the AI works with the network unplugged.

  • A desktop of its own

    The desktop, synui, is written for SynapseOS. Windows tile or fill the screen, with blur and shadows; workspaces can be shared across monitors or kept per monitor, and can turn like a cube. HDR displays work. There are fifteen themes, and a CRT filter for anyone who misses old monitors.

  • Apps that belong together

    Files, software, settings, a text editor, a disk utility, a calendar, a media player, a locked folder and a disk cleaner, all written for SynapseOS. Each has a window and a command-line version, and all of them follow the theme. The terminal, syntty, is 359 KB and opens in 5.8 ms.

  • Your language from the first screen

    Choose from fourteen languages in the boot menu and the installer and every app use it from then on: English, German, French, Spanish, Portuguese, Italian, Dutch, Polish, Russian, Japanese, Chinese, Korean, Hindi and Arabic. Arabic reads right to left.

  • Good on a TV

    Big screen mode (Super+F10, or the Guide button on a controller) puts your Steam library, Big Picture, a browser, music, and any Plex or Jellyfin server on your network onto the television. A controller drives all of it, and works as a mouse too.

  • Installs beside what you have

    The installer can use the whole disk, with full-disk encryption if you want it. On a UEFI machine that already has another system, it can go into the free space beside it and leave that system alone. Four filesystems and three bootloaders to choose from.

  • Security you can see

    synguard watches system calls, scores anything that looks risky, and shows its verdicts on the desktop. It can also block in the kernel. The firewall asks about each new network, and the malware scanner tells you what it found.

The desktop

The settings, wallpaper picker, dock, cursor picker, sound panel and control panel are all drawn by synui itself. The top bar and the desktop widgets run on quickshell.

A fresh install starts in the Prism theme: a dark, see-through surface that takes its colour from your wallpaper and passes it on to the bar, the dock, the icons, and any RGB lighting in the machine. Fifteen themes ship, including a light one, and a slider sets how much of the desktop shows through.

The top bar takes widgets in Omarchy’s shell-plugin format, so a widget written for one works on both. Browse and install them with synui-plugins browse, a terminal browser, or a window.

Under the hood

One service, synapd, loads the model once. Everything else asks it over a local socket: the shell, the desktop assistant, the security monitor and the network filter. So the model takes up memory once, however many things are using it.

Each part has its own folder and PKGBUILD in the source tree. Twenty-four are also published from their own repositories under github.com/velle999, so the desktop, the terminal, the apps and the AI service install on a plain Arch system too.

PartWhat it does
synapdRuns the local model through llama.cpp and answers every other part over a Unix socket. Drops root after it starts.
synshThe shell. Use it like any shell, or type what you want in plain English.
synuiThe Wayland compositor, on wlroots 0.20 and scenefx 0.5: tiling and monocle layouts, workspaces per monitor, XWayland, layer-shell, glass, blur and shadows.
synguardSecurity monitor. Sorts system-call events, scores threats and sends its verdicts to the desktop. Can also enforce in the kernel through BPF-LSM.
synnetNetwork policy daemon, using nftables.
synapse_kmodKernel module (DKMS) for system-call monitoring and AI scheduling hints, published under /sys/kernel/synapse/.
synttyThe default terminal. It draws on the CPU with no GL at all: 359 KB, a window in 5.8 ms, tabs, images and OSC 133 prompt marks.
synpkgThe package manager: one C program over libalpm for the Arch repositories, the AUR, Flathub, BlackArch and SynapseOS’s own parts, as a command, a terminal browser and a window.
synstudioPhoto and video editing with one colour engine, so a photo and a video frame graded the same way come out the same. Edits are saved beside the file and the original is never changed.
synfilesThe file manager: trash, undo, split view, thumbnails, archives and search, as a window, a terminal browser or a command.
syn-settingsDisplays, keyboard and language, date and time, network, Bluetooth, power, kernels, default apps, startup apps and user accounts. Each page shows which file a setting came from.
syn-editThe text editor: one modal engine behind a terminal editor, a window, and a scripting mode.
syn-calCalendar for CalDAV, Google Calendar and Microsoft 365, as a window, a terminal view and a command. Appointments are kept as plain .ics files in a folder.
syn-playMedia player built on mpv: playlists, shuffle, quick open and history.
syn-vaultA folder with a password. It opens at ~/Vaults/<name>, stays encrypted on disk with gocryptfs, and appears in the file manager’s sidebar.
syn-cleanDisk cleanup across ten categories, and secure delete for files and folders. Both are in the file manager’s right-click menu too.
syn-disksThe disk utility: drives, health, mounting, safe removal, formatting and partitioning. It refuses to format a disk the running system is on.
syn-arcadeThe game helper: the MangoHud overlay, controllers outside Steam, SDL mapping overrides, and big screen mode.
syn-confineRuns a command inside a Landlock sandbox that everything it starts inherits.
syn-arsenalBrowse and install about 5,000 BlackArch security tools by category, in a window or a terminal.
vibeThe desktop assistant, as a chat window and a terminal, on the local model or on Claude or OpenAI with a key. Opens apps, folders and panels, changes settings, reads and edits files, and runs commands inside syn-confine’s sandbox. Asks before it changes anything.
chibiA voice companion that also keeps an eye on synguard’s verdicts.
syn-updateUpdates the SynapseOS side of an installed system, rebuilding only the parts that changed.

Download and install

SynapseOS 1.0.1 is the current release. It adds signed updates, a firewall that asks about each network, and a malware scanner that tells you what it found. It’s free, for 64-bit PCs, and the ISO is about 4.6 GiB. The AI model downloads during installation.

  1. Download the ISO

    Download SynapseOS 1.0.1 Mirror Torrent

    One file, and your browser can resume it. The mirror and the torrent are on the Internet Archive.

    Or download it in parts from GitHub

    The GitHub release has the same image split into three parts, because GitHub limits a file to 2 GiB. Download all the .part* files and the .sha256 into one folder, then join them:

    Linux / macOS

    cat SynapseOS-1.0.1-x86_64.iso.part* > SynapseOS-1.0.1-x86_64.iso
sha256sum -c SynapseOS-1.0.1-x86_64.iso.sha256   # shasum -a 256 -c on macOS

    Windows

    In Command Prompt, in the folder you downloaded to:

    copy /b SynapseOS-1.0.1-x86_64.iso.part00 + SynapseOS-1.0.1-x86_64.iso.part01 + SynapseOS-1.0.1-x86_64.iso.part02 SynapseOS-1.0.1-x86_64.iso
certutil -hashfile SynapseOS-1.0.1-x86_64.iso SHA256

    Name every part, in order, joined by +, and keep the /b. Without it, copy stops early and leaves a short file that won’t boot, with no error.

  2. Check that it arrived whole

    A download that stopped early can still look like a normal ISO. The checksum tells you it’s complete.

    Linux / macOS

    curl -O https://dl.soslinux.org/SynapseOS-1.0.1-x86_64.iso.sha256
sha256sum -c SynapseOS-1.0.1-x86_64.iso.sha256   # shasum -a 256 -c on macOS

    Windows

    In PowerShell, in the folder you downloaded to:

    (Get-FileHash -Algorithm SHA256 .\SynapseOS-1.0.1-x86_64.iso).Hash -eq `
  (((Get-Content .\SynapseOS-1.0.1-x86_64.iso.sha256) -split '\s+')[0]).ToUpper()

    True means it’s intact. In Command Prompt, certutil -hashfile SynapseOS-1.0.1-x86_64.iso SHA256 prints the checksum for you to compare with the .sha256 file.

  3. Check who built it optional

    The checksum comes from the same server as the ISO, so it can’t tell you who made the image. The signature can. Its key’s fingerprint is also kept in the source repository, in archiso/release-key.fingerprint, on a different host. Check that what gpg prints, what’s on this page, and what’s in the repository all match.

    Linux / macOS

    curl -O https://soslinux.org/synapseos-release-key.asc
gpg --import synapseos-release-key.asc

gpg --verify SynapseOS-1.0.1-x86_64.iso.asc SynapseOS-1.0.1-x86_64.iso

    A good result says Good signature from "SynapseOS Release Signing", with this fingerprint: 

    6548 9EF5 C20D 0BD9 4211  472B ED33 6DB7 952B 609E

    gpg also says the key is not certified with a trusted signature. That’s normal: you haven’t marked the key as trusted in GnuPG. Matching the fingerprint is the check.

    Windows

    Install Gpg4win and the same three commands work in PowerShell.

    Releases from 0.2.9.5 on are signed. Earlier ones, including 0.2.9.4, have no signature to check.

  4. Write it to a USB stick

    This erases the stick. Copy off anything you want to keep first.

    Linux / macOS

    sudo dd if=SynapseOS-1.0.1-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync

    Find the stick with lsblk first, and write to the whole disk (/dev/sdb), not a partition on it (/dev/sdb1).

    Windows

    • Rufus: pick the ISO, press START, and choose DD Image mode when it asks.
    • balenaEtcher: nothing to set.
    • Ventoy: copy the .iso onto a stick that already has Ventoy and pick it from Ventoy’s menu. This one doesn’t erase the stick.

  5. Start from the stick and install

    Restart with the stick plugged in and choose it from the boot menu (usually F12, F11, Esc or Del as the machine starts). Secure Boot needs to be off, or SynapseOS enrolled: see Secure Boot. Then run syn-install from the live desktop.

    The installation guide walks through every choice the installer offers.

Or try it in a virtual machine first

git clone https://github.com/velle999/SYNAPSE.git && cd SYNAPSE
QEMU_RAM=8G ./archiso/build_scripts/qemu-test.sh

The script finds the newest ISO, uses KVM when it can, boots UEFI through OVMF, and attaches a 20 GB test disk that keeps its contents.

What you need

  • Processor: 64-bit (x86_64). The AI runs on the CPU by default.
  • Memory: 8 GB or more, because the model stays loaded.
  • Disk: about 25 GB, plus room for the model.
  • Internet: once, during installation, to download the model.
  • Graphics card: optional. NVIDIA through CUDA; AMD and Intel through Vulkan.
  • Firmware: UEFI or BIOS. Installing beside another system needs UEFI.

Questions

Does SynapseOS send anything to the cloud?

No. The installer downloads the model once. After that it lives on your disk and runs through llama.cpp on your machine. There’s no API key or account, and the AI works offline.

Is it just Arch with an app on top?

No. The model runs as a system service and the rest of the system uses it: the shell turns your words into commands with it, the desktop talks to it, and the security monitor uses it to sort events. The desktop, the shell, the security monitor, the network daemon and the kernel module are all written for SynapseOS.

Do I need a graphics card?

No. The model runs on the CPU by default, on any 64-bit PC. If you have an NVIDIA, AMD or Intel graphics card, you can install a faster build afterwards.

Is it free and open source?

Yes. SynapseOS’s own code is GPL-2.0-or-later, except the kernel module, which is GPL-2.0-only like the Linux kernel. All of it is on GitHub.

Can I use it every day?

Yes. Its author does, and at 1.0 it’s ready for you to do the same. It’s a rolling release, so it keeps updating after you install it. A virtual machine is still the quickest way to look around first.

How do updates work?

There are two commands, one for each half of the system. sudo pacman -Syu updates the Arch packages, and syn-update check and syn-update apply update the SynapseOS parts. The second also has a window in the start menu.
